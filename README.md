# Task Manager App

A modern and interactive task management web application built with HTML, CSS, JavaScript, Tailwind CSS, and Vite.

---

## Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- Responsive design
- Interactive UI
- Built with Tailwind CSS
- Powered by Vite
